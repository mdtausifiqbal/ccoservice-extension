# CCO Service

A Chrome Extension, built for CCO and Serivce Franchisee of Voltas, Carrier, Midea and Daikin

## Key Features 
- Add **copy** button to CRM of Voltas, Carrier Midea, and Daikin

## Tech Stack
- Typescript
- WXT Framework
